# Mohsen L2TP VPN — independent test implementation

یک نمونهٔ آزمایشی مستقل برای اتصال L2TP/IPsec از اندروید ۷ به بعد. سورس برنامه با Kotlin برای همین پروژه نوشته شده و سورس یک اپ VPN ثالث در این مخزن کپی نشده است. قالب بسته‌ها و مذاکره بر پایهٔ استانداردهای عمومی IKEv1/IPsec، L2TPv2 و PPP است.

> **وضعیت:** آلفای آزمایشی. این پیاده‌سازی هنوز در برابر سرور واقعی شما تست اتصال نشده و بازبینی امنیتی مستقل ندارد. موفق‌شدن GitHub Actions فقط یعنی APK کامپایل شده؛ اثبات نمی‌کند که مذاکره با هر سرور سازگار است. برای اطلاعات VPN حساس/عملیاتی، ابتدا از سرور تست و حساب آزمایشی استفاده کنید.

## قابلیت‌ها

- حداقل نسخهٔ هدف: Android 7.0 / API 24.
- فرم فارسی برای آدرس سرور، نام کاربری و رمز PPP و IPsec Pre-Shared Key.
- شروع و قطع اتصال، وضعیت مرحله‌ای و گزارش محلی برای عیب‌یابی.
- شمارش بایت‌های ارسالی/دریافتی از رابط TUN و زمان اتصال.
- ذخیرهٔ محلی فیلدهای پروفایل با AES-GCM و کلید موجود در Android Keystore؛ پشتیبان‌گیری Android برای اپ غیرفعال است.
- تونل IPv4؛ ترافیک IPv6 عمداً از رابط VPN عبور داده و حذف می‌شود تا در این نسخه از مسیر عادی نشت نکند.
- هیچ سرویس تحلیلی/ردیابی یا API برنامه‌ای ثالث در زمان اجرا استفاده نشده است. اطلاعات لازم برای احراز هویت فقط به سرور VPN پیکربندی‌شده ارسال می‌شود. اگر سرور DNS ارائه نکند، برنامه برای DNS از `1.1.1.1` به‌عنوان fallback استفاده می‌کند؛ در آن حالت پرس‌وجوهای DNS به Cloudflare می‌رسند، نه اطلاعات ورود VPN.

## محدوده و سازگاری پروتکل

نسخهٔ فعلی روی L2TPv2 داخل IPsec با IKEv1 و PSK متمرکز است. در مرحلهٔ IPsec، AES-CBC و الگوریتم‌های یکپارچگی متداول SHA-1/SHA-256 مذاکره می‌شوند؛ در PPP، PAP و CHAP-MD5/MS-CHAPv2 پیاده‌سازی شده‌اند. سرورهایی با تنظیمات رمزنگاری متفاوت ممکن است وصل نشوند. PPTP در این نسخه پیاده‌سازی نشده است.

## ساخت APK روی GitHub

1. فایل ZIP پروژه را استخراج کنید. **محتویات پوشه** را در ریشهٔ مخزن `imohsen7/L2TP-VPN-Android` قرار دهید؛ ZIP را به‌تنهایی به مخزن اضافه نکنید. پوشهٔ مخفی `.github/workflows` باید همراه پروژه آپلود شود.
2. همهٔ فایل‌ها را commit و push کنید. Workflow با نام **Build custom L2TP VPN APK** روی `main` یا `master` به‌صورت خودکار اجرا می‌شود. می‌توانید آن را از بخش **Actions → Build custom L2TP VPN APK → Run workflow** نیز دستی اجرا کنید.
3. پس از اتمام موفق Job، صفحهٔ اجرای Workflow را باز کنید و از بخش **Artifacts** فایل `MohsenL2TP-debug-apk` را دانلود و استخراج کنید. APK درون آن `app-debug.apk` نام دارد و با کلید debug ساخته شده است.

Workflow ابتدا تست‌های واحد رمزنگاری/قالب بسته را اجرا می‌کند و بعد APK را می‌سازد. ابزارهای Android SDK و Gradle فقط در زمان build به‌کار می‌روند؛ وابستگی کتابخانه‌ای زمان اجرا در خود اپ اضافه نشده است.

## آزمایش اتصال

- از یک پروفایل L2TP/IPsec PSK واقعی اما آزمایشی استفاده کنید. آدرس سرور باید از دستگاه قابل دسترس باشد.
- ارتباط خروجی UDP/500 و UDP/4500 تا سرور باید مجاز باشد؛ سرور نیز باید L2TP/IPsec با NAT-T و الگوریتم‌های مورد مذاکره را قبول کند.
- Android هنگام اولین اتصال پنجرهٔ مجوز VPN را نشان می‌دهد؛ آن را تأیید کنید.
- در صورت خطا، متن کامل گزارش داخل برنامه و لاگ سرور را مقایسه کنید. **رمز PPP یا PSK را در issue یا پیام عمومی ارسال نکنید.**

## محدودیت‌های فعلی

- هنوز اتصال واقعی روی مدل‌های مختلف سرور/روتر آزمایش نشده است.
- تونل داده IPv4 دارد؛ IPv6 از داخل تونل پشتیبانی نمی‌شود.
- بازاتصال خودکار، ذخیرهٔ چند پروفایل و PPTP خارج از محدودهٔ نسخهٔ اول است.
- این کد آلفاست و برای استفادهٔ حساس/تولیدی باید بازبینی پروتکل، بازبینی رمزنگاری و آزمون interoperability انجام شود.
